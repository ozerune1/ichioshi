Fonts built into the app:

- Inter (Regular, Medium, SemiBold, Bold), from Inter.ttc: the app's
  typeface. SIL Open Font License (Inter-LICENSE.txt).
- Symbols-DejaVu.ttf: the few symbols the app's icons use that Inter lacks
  (≡ ─ ▦ ◷ ⚙ ✦ ☰ ⋯), subset from DejaVu Sans (DejaVu-LICENSE.txt).
- Symbols-Noto.ttf: ⌕, subset from Noto Sans Symbols. SIL Open Font
  License (Noto-LICENSE.txt).
